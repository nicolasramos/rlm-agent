# Lessons

## kernel-socket-accept-loop

- **cue**: detached kernel daemon silently serves a FRESH namespace after the client reconnects; variables appear lost (NameError) right after a transport restart.
- **lesson**: Keep the Unix-socket accept loop off the request-processing thread; a main loop blocked in `requests.get()` never returns to `accept()`, so reconnects queue in the backlog and the ready frame never arrives.
- **evidence**: `tests/test_mcp_server.py::test_state_survives_server_recycle` failed with `Error (NameError): name 'x' is not defined` until kernel.py got a dedicated acceptor thread; after the fix the same test passed (9/9).
- **confidence**: high

## macos-tmp-realpath-hash

- **cue**: a lake/key file computed from `sha256(project_dir)` is "missing" although the component that wrote it logged success.
- **lesson**: Hash `os.path.realpath(cwd)` (or always the same form) when deriving per-project keys — on macOS `os.getcwd()` in a spawned subprocess returns the physical path (`/private/tmp/...`) for logical `/tmp/...` paths, so components hashing different forms derive different keys.
- **evidence**: rlm_guard_hook wrote `state/lake/5593ae7e4868beec.jsonl` while the test expected `sha256("/tmp/.../project") = 5327dee1444d9cb5`; `sha256("/private/tmp/.../project") = 5593ae7e4868beec` matched the file.
- **confidence**: high
